Happy Tails Animal Shelter — Computed Age

Elena has raised a small but recurring issue: staff frequently need to know an animal's age at a glance — for medical assessments, adoption suitability, and general record-keeping — but today they have to manually calculate it from the birth date every time. Since the animals model already stores a birth date, this age should simply be calculated automatically by the system rather than left to manual arithmetic.

The Task


  1. Add a computed age field

    In animals.py, add a new field called age that is automatically calculated from the animal's existing birth_date field, rather than entered manually by staff.

  2. Define the compute method and dependencies

    Using the api library, define a compute method that calculates the animal's age based on birth_date. Ensure the field recalculates automatically whenever birth_date changes, using the appropriate dependency declaration.

  3. Calculate the age difference accurately

    Rather than manually comparing years, months, and days yourself, use the relativedelta function from Python's dateutil.relativedelta module (already available in Odoo) to calculate the difference between today's date and the animal's birth_date.

    relativedelta returns an object with .years, .months, and .days attributes — the .years attribute is what you want for the age field.

  4. Handle missing birth dates

    Remember to handle the case where birth_date is not set, so the compute method doesn't error out on an empty value.

  5. Display the field in the view

    Display the new age field in the form view alongside the animal's other details.

By the end of this task, every animal record should automatically display its current age, calculated directly from its birth date, with no manual entry required from staff.
