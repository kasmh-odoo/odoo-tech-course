Happy Tails Animal Shelter — Search, Kanban, and Domains

As the number of animal records grows, staff have started struggling to find specific animals quickly, especially when trying to check on a particular type of animal or everything currently housed in a given location. Elena has also mentioned that the list view, while functional, doesn't give her the quick visual overview she wants when scanning through animals at a glance — she'd prefer something closer to a set of cards she can browse and group on the fly.

At the same time, Dr. Aris has raised a data quality concern: right now, nothing stops staff from assigning a vet who works at a different location than the animal, picking a sponsor who isn't actually qualified to sponsor animals, or releasing an animal to a country that was never approved as one of its allowed release destinations. These relationships should be enforced by the form itself, not left to staff to double-check manually.

The Task

  1. Add a search view

    In animals_views.xml, create a new view record using the search architecture type, allowing staff to search animals by:

    • Name
    • Animal Type
    • Animal Location
  2. Add group-by filters

    Within the same search view, add custom "Group By" filters for:

    • Animal Type
    • Animal Status
  3. Add a kanban view

    In animals_views.xml, create a new view record using kanban tags, with the following requirements:

    • Use the card template.
    • Display the animal's name and status on each card.
    • Display the assigned vet only if a vet has actually been assigned to the animal.
    • Group animals by animal type by default.
    • Update the corresponding window action so that kanban is included in the view modes — otherwise the kanban view won't be reachable.
  4. Add domains to restrict relational fields

    On the animal form, add domains so that:

    • The assigned vet can only be selected from vets located at the same location as the animal.
    • The sponsor can only be selected from partners marked as qualified sponsors.
    • The released country can only be selected from the animal's list of allowed release countries.

By the end of this task, staff should be able to search and filter animals by name, type, and location, browse them visually through a kanban board grouped by type, and be guided — through enforced domains — toward only valid combinations of vet, sponsor, and release country when filling out an animal's record.
