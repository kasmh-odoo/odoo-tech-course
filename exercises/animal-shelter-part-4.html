Happy Tails Animal Shelter — Related Models and Relationships

As Happy Tails continues to formalize its record-keeping, it has become clear that an animal's profile cannot exist in isolation. Every animal is associated with a category of species, a physical location within the shelter, and a history of vaccinations — none of which are currently represented anywhere in the system. Additionally, the shelter needs to track supporting relationships such as which staff veterinarian is responsible for an animal, whether it has a sponsor, and which countries it may eventually be released or relocated to.

Rather than storing all of this as flat text on the animal record, this information needs to live in its own dedicated models and be properly linked back to the animals model, so that relationships between animals, staff, locations, and external parties can be tracked and reported on reliably.

The Task

  1. Create three new models

    Add three new Python files under the models folder, one for each of the following models:

    • animal.location
    • animal.type
    • animal.vaccine

    Each of these three models should have a mandatory name field.

  2. Extend the animals model with relational fields

    On the animals model, add the following fields:

    • animal_type_id — a Many2one field linking to animal.type
    • animal_vaccine_ids — a Many2many field linking to animal.vaccine
    • animal_location_id — a Many2one field linking to animal.location
    • release_countries_ids — a Many2many field linking to res.country
    • sponsor_id — a Many2one field linking to res.partner
    • vet_id — a Many2one field linking to hr.employee
    • released_country_id — a Many2one field linking to res.country
    • vet_phone — a related field that pulls the work phone of the linked veterinarian
    • released_country_ids — a Many2many field linking to res.country
  3. Link locations back to animals

    On animal.location, add an animal_id field — a One2many field linking back to animals.

  4. Wire up the new models
    • Import all three new model files in __init__.py.
    • Add access rights for animal.location, animal.type, and animal.vaccine in ir.model.access.csv.
  5. Build views for the new models

    Create three new XML files under the views folder:

    • animal_type_views.xml
    • animal_location_views.xml
    • animal_vaccine_views.xml

    Each file should include a list view, a form view, and a window action for its respective model.

  6. Expand the navigation menu

    In animals_menus.xml:

    • Add a second top-level menu called Specification, containing a dropdown with two submenus: Animal Types and Animal Vaccines.
    • Add a third top-level menu called Shelter, containing a submenu for Animal Location.

By the end of this task, the animals model should be fully connected to its supporting data — type, location, vaccination history, veterinarian, sponsor, and release destinations — and staff should be able to navigate to and manage each of these related models directly from the Animal Shelter app.
